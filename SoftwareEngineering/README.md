# Software Engineering

> Language-agnostic knowledge for building production systems at scale.

## Topics

| Area | Focus |
|------|-------|
| **Architecture** | Patterns, distributed systems, trade-offs |
| **Design** | Product design, API design |
| **Product Engineering** | Agile, CI/CD, DevOps culture |
| **Project Management** | Estimation, planning, retrospectives |

## Structure

```
SoftwareEngineering/
  architecture/
    patterns/              # Microservices, Event-Driven, CQRS, etc.
    distributed-systems/   # CAP, Consensus, Replication, Sharding
  design/
    product-design/        # User stories, wireframing, MVP
    api-design/            # REST, GraphQL, gRPC, versioning
  product-engineering/     # Agile, Scrum, Kanban, CI/CD
  project-management/      # Estimation, planning, stakeholders
```

## How to Use

Each subdirectory contains a README with:
- Core concepts and definitions
- Trade-offs and when to use what
- Interview talking points
- References for deeper reading
