# Java Language Guide

Java interview preparation with structured categories for DSA, design, and CS fundamentals.

## Directory Structure

All Java code lives under `Languages/java/`.

## Categories

| Category | Topics | Path |
|----------|--------|------|
| **Algorithms & DSA** | Coding patterns, LeetCode solutions | `Languages/java/algorithms-dsa/` |
| **Low-Level Design** | SOLID, Design Patterns, OOP Problems | `Languages/java/low-level-design-lld/` |
| **System Design HLD** | Scalability, distributed systems | `Languages/java/system-design-hld/` |
| **Computer Core** | OS, Networking, Databases | `Languages/java/computer-core/` |
| **Application Core** | JVM internals, Collections, Streams, Concurrency | `Languages/java/application-core/` |
| **Frameworks & Libraries** | Spring Boot, Hibernate, JUnit, Maven/Gradle | `Languages/java/frameworks-libraries/` |

## Quick Start

```bash
cd Languages/java
javac algorithms-dsa/**/*.java
java -cp . algorithms.dsa.patterns.TwoPointers
```
