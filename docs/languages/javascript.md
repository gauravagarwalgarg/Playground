# JavaScript Language Guide

JavaScript/TypeScript interview preparation with DSA, design patterns, and CS fundamentals.

## Directory Structure

All JS code lives under `Languages/javascript/`. Uses `package.json` for dependency management.

## Categories

| Category | Topics | Path |
|----------|--------|------|
| **Algorithms & DSA** | Coding patterns, LeetCode solutions | `Languages/javascript/algorithms-dsa/` |
| **Low-Level Design** | SOLID, Design Patterns, OOP Problems | `Languages/javascript/low-level-design-lld/` |
| **System Design HLD** | Frontend architecture, scalability | `Languages/javascript/system-design-hld/` |
| **Computer Core** | Event loop, networking, browser APIs | `Languages/javascript/computer-core/` |
| **Application Core** | Closures, prototypes, async/await, modules | `Languages/javascript/application-core/` |
| **Frameworks & Libraries** | React, Node.js, Express, testing | `Languages/javascript/frameworks-libraries/` |

## Quick Start

```bash
cd Languages/javascript
npm install
node algorithms-dsa/patterns/two_pointers.js
```
