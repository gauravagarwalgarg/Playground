# Reading List

> Books that shaped how I think about software, systems, and engineering.

---

## Systems & Architecture

| Book | Author | Key Takeaway |
|------|--------|-------------|
| **Designing Data-Intensive Applications** | Martin Kleppmann | The bible of distributed systems. Replication, partitioning, consistency, batch/stream processing. |
| **System Design Interview Vol 1 & 2** | Alex Xu | Structured approach to HLD problems. Estimation, API design, deep dives. |
| **Building Microservices** | Sam Newman | When to split, how to communicate, deployment patterns. |
| **Software Architecture: The Hard Parts** | Neal Ford et al. | Trade-off analysis for distributed architectures. |

## Software Craft

| Book | Author | Key Takeaway |
|------|--------|-------------|
| **Clean Code** | Robert C. Martin | Naming, functions, comments, formatting. The basics that compound. |
| **The Pragmatic Programmer** | Hunt & Thomas | DRY, orthogonality, tracer bullets, rubber ducking. |
| **Refactoring** | Martin Fowler | Systematic code improvement without changing behavior. |
| **A Philosophy of Software Design** | John Ousterhout | Deep modules, complexity management, strategic programming. |

## Computer Science

| Book | Author | Key Takeaway |
|------|--------|-------------|
| **Structure and Interpretation of Computer Programs** | Abelson & Sussman | Abstraction, recursion, interpreters. Foundational thinking. |
| **Introduction to Algorithms (CLRS)** | Cormen et al. | The reference for algorithms and data structures. |
| **Operating Systems: Three Easy Pieces** | Arpaci-Dusseau | Virtualization, concurrency, persistence. Free online. |
| **Computer Networking: A Top-Down Approach** | Kurose & Ross | HTTP, TCP, routing, link layer. Application-first perspective. |

## AI & Machine Learning

| Book | Author | Key Takeaway |
|------|--------|-------------|
| **Deep Learning with Python** | Francois Chollet | Keras/TensorFlow practical guide. CNNs, RNNs, transformers. |
| **Hands-On Machine Learning** | Aurelien Geron | Scikit-learn to TensorFlow. End-to-end ML projects. |
| **AI Engineering** | Chip Huyen | MLOps, model serving, monitoring, data pipelines. |

## Embedded & Hardware

| Book | Author | Key Takeaway |
|------|--------|-------------|
| **Making Embedded Systems** | Elecia White | Patterns for firmware. State machines, interrupts, power management. |
| **The Art of Electronics** | Horowitz & Hill | Circuit design from first principles. |
| **Linux Device Drivers** | Corbet, Rubini, Kroah-Hartman | Kernel modules, char devices, memory mapping. |

## Leadership & Product

| Book | Author | Key Takeaway |
|------|--------|-------------|
| **The Manager's Path** | Camille Fournier | IC to CTO progression. Tech lead, manager, director roles. |
| **An Elegant Puzzle** | Will Larson | Systems thinking for engineering management. |
| **Inspired** | Marty Cagan | Product discovery, empowered teams, outcome over output. |

---

## How I Read

1. **First pass**: Skim TOC, read intro/conclusion of each chapter
2. **Second pass**: Read fully, highlight key ideas
3. **Third pass**: Write notes in this repo (see `Notes/`)
4. **Apply**: Implement concepts in `Languages/` code or real projects
